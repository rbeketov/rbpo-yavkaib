# Область безопасности TaskFlow

TaskFlow — локальный учебный MVP. Поддерживается только демонстрация на `127.0.0.1` с синтетическими аккаунтами. Промышленная эксплуатация и публичный доступ не проверялись и не входят в предполагаемый выпуск.

Сервер проверяет роль для проекта, CSRF и допустимые поля; шаблоны экранируют текст. Есть автоматические негативные тесты. Ограничения: нет ограничения частоты входа, внешнего аудита, защиты от доверенного администратора ОС/SQLite и гарантии отсутствия неизвестных дефектов. `check --deploy` оценивает настройки, а не защищённость реальной инфраструктуры.

Секрет приложения генерируется локально; `.env` и БД не публикуются. Demo-пароль выбирает оператор. Не используйте реальные пароли или данные для учебных проверок.

Если обнаружена проблема, сохраните минимальное воспроизведение на синтетических данных, точную версию и ожидаемое/фактическое поведение. Передайте сведения участникам через уже согласованный канал; не публикуйте реальные секреты, cookie или чужие данные в Issues. Специальный приватный канал раскрытия в GitHub здесь не заявлен как настроенный.

Целевой порядок: ведущий компонента разбирает сообщение в течение двух учебных дней, партнёр проверяет вывод. При риске доступа/секретов прекратить использование затронутой версии, затем исправить, повторить проверки и создать новый тег. Это учебный порядок без круглосуточного SLA; решение о продуктовом выпуске принимают оба участника по §4 [project.md](project.md).
